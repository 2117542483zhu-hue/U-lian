# 接入大模型（五分钟搞定）

现在网站的两种状态：

| 状态 | 表现 |
| --- | --- |
| 未配置 | 教练建议、督导文案由代码里的规则生成，页面标签是灰底"规则生成" |
| 已配置 | 同样的位置由大模型生成，标签变成蓝底"大模型生成" |

所以比赛演示前**一定要把 Key 填上**，否则评委看到的全是规则文本。

## 一、申请一个 Key

推荐 DeepSeek，中文好、便宜（充 10 元够演示几百次）。也可以选其它平台，代码里都已经适配好。

| 平台 | 申请地址 | 默认模型 | 备注 |
| --- | --- | --- | --- |
| DeepSeek（推荐） | https://platform.deepseek.com/api_keys | deepseek-chat | 注册后充值，创建 API Key，形如 `sk-` 开头 |
| 通义千问 | https://bailian.console.aliyun.com/ | qwen-plus | 阿里云百炼，新用户通常有免费额度 |
| 智谱 GLM | https://open.bigmodel.cn/usercenter/apikeys | glm-4-flash | glm-4-flash 一般有免费额度 |
| 月之暗面 Kimi | https://platform.moonshot.cn/console/api-keys | moonshot-v1-8k | 注册即送少量额度 |
| 火山方舟（豆包） | https://console.volcengine.com/ark | doubao-seed-1-6 | 需要先在控制台开通模型 |

注册、实名、充值、创建 Key，把这四步做完即可。**Key 只显示一次，复制后先粘到记事本里。**

## 二、填到网站里

1. 打开网站，进入左侧的「我的与计划」；
2. 找到最下面的大模型接入面板；
3. 平台选 DeepSeek，模型名留空（默认 deepseek-chat），把 Key 粘贴到 API Key 输入框；
4. 点「保存并测试」。

出现绿底的「连接成功」，并且模型真的回了一句话，就说明接通了。此时回到动作自检页，重新分析一次视频，教练建议的标签会变成「大模型生成」。

Key 保存在 `配置\ai配置.txt`，也可以直接编辑这个文件，格式如下：

```
provider=deepseek
deepseek_key=sk-你的密钥
deepseek_model=deepseek-chat
```

## 三、大模型具体接管了哪些位置

| 位置 | 大模型做什么 | 没配 Key 时 |
| --- | --- | --- |
| 动作自检的教练建议 | 把"膝角 63 度、前倾 48 度"翻译成教练口吻的纠正建议 | 用规则文案拼接 |
| 训练记录的解析 | 把"今天深蹲 60 公斤 5 组 5 次，最后一组有点吃力"解析成结构化字段 | 用正则表达式解析 |
| 督导消息 | 三天没练时生成追问与降级方案 | 用固定模板 |
| 营养建议话术 | 让补齐方案读起来更自然 | 用模板句子 |

注意：**加重重量、热量缺口、动作判定这些数值永远由代码计算**，大模型只负责说人话。这个分工在答辩时是加分项，因为评委最关心的就是"你的数字是不是模型猜的"。

## 四、常见问题

**提示 401 或 Authentication Fails**：Key 复制不完整，或者复制到了带空格的版本。重新复制一次，注意不要带引号。

**提示余额不足**：去平台充值，通常 10 元就够整个比赛演示使用。

**提示模型不存在**：模型名写错了，或者该平台需要先在控制台开通对应模型（火山方舟最常见）。把模型名留空即可使用默认值。

**超时**：服务器到模型平台的网络不通。换个平台试，或者确认服务器所在网络没有限制访问外网。

**填了 Key 但标签还是"规则生成"**：说明调用失败了，只是页面自动降级了。回到这个面板点「只测试连接」，会显示具体的错误原因。

## 五、安全提醒

1. Key 保存在本机文件里，不要把这个文件传到公开仓库或网盘；
2. 给 Key 设置消费上限，避免泄漏后被刷；
3. 比赛结束后可以到平台把 Key 删除。

## 六、拍照识别需要视觉模型

食堂营养页的「拍照识别」需要一个**能看图**的模型。DeepSeek 只有文字模型，不能识图，所以只填 DeepSeek 时这个功能会显示"未接入视觉模型"。

### 为什么不用让用户自己绑定

密钥统一填在服务器上，**填一次，所有打开这个网站的人都直接用**，不需要每个人各自申请和绑定。这也是真实产品的做法：用户的账号里有额度，服务端的密钥只在后台。

严格说云端 AI 没有"零密钥"的接入方式，密钥是平台识别调用方的唯一凭据。想彻底不用密钥，只能在本机跑开源视觉模型（例如 Ollama 加载 qwen2-vl），需要独立显卡和几个 GB 的模型下载，比赛用的机器上不现实。

### 推荐：智谱 glm-4v-flash（免费）

| 平台 | 视觉模型 | 说明 |
| --- | --- | --- |
| 智谱 GLM | `glm-4v-flash` | **推荐，目前免费**，申请地址 https://open.bigmodel.cn/usercenter/apikeys |
| 通义千问 | `qwen-vl-plus` | 百炼平台，新用户通常有免费额度 |
| 火山方舟 | `doubao-seed-1-6` | 需要先在控制台开通视觉模型 |
| 月之暗面 Kimi | `moonshot-v1-8k-vision-preview` | 注册送少量额度 |

### 怎么填

进入「我的与计划」页最下面的「大模型接入（服务器配置）」，平台下拉里能看出哪些支持看图：

- DeepSeek 后面标着「仅文字」
- 其它四个平台标着「支持看图」

选智谱 GLM，把 Key 粘进去，点「保存并测试」。之后回到食堂营养页，拍照识别面板的标签会变成「已接入 智谱 GLM」。

**文字和视觉可以来自不同平台**：程序会优先用配置里指定的平台做文字任务，做视觉任务时自动跳到第一个既填了 Key 又支持看图的平台。所以你可以文字用 DeepSeek、识图用智谱，互不影响。

### 识别的原理

视觉模型只负责两件事：**认出这是哪道菜**、**估计有几份**。热量和蛋白质不靠模型估算，而是拿识别出的菜品去查自己的菜品库（40 道菜的标准值），再乘以份数。

这样做的好处是数字可核查：模型的输出只有"第 11 号菜、1.5 份"，而 270 千卡、6 克蛋白质这些数值来自菜品库，评委可以当场对表。识别结果里每个菜都会显示可信度与判断依据，份数可以用加减按钮调整后再加入今日摄入。
