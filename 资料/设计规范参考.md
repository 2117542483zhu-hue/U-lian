# 界面设计规范

界面采用**暗色毛玻璃**风格，设计依据是 Apple 在 WWDC 分享的界面设计方法（《Designing Fluid Interfaces》《The Details of UI Typography》《Principles of Great Design》），转译成 CSS 实现。整份规范落在 `网页端\static\style.css` 顶部的变量区，改一处即可全局生效。

## 一、材质层级

Apple 的界面结构靠"材质轻重"表达层级，而不是靠边框和分隔线。我们落成四层：

| 层级 | 用途 | 实现 |
| --- | --- | --- |
| 环境层 | 页面最底，给玻璃提供可折射的内容 | 固定的深色底 + 三团模糊光斑（蓝、紫、青） |
| 结构材质 | 侧边栏 | 更暗更重：`rgba(16,20,28,.72)` + `blur(34px)` + 深阴影 + 右侧渐隐边 |
| 交互材质 | 卡片、提示条 | 较亮：`rgba(255,255,255,.055)` + `blur(24px)` + 1px 边框 + 顶边高光 |
| 凹陷区域 | 输入框、表格头、指标格、纠正练习块 | 比卡片更暗：`rgba(8,11,17,.42)` |

关键一条：**两种浅色半透明不叠加**。卡片内部如果再用一层浅色玻璃，文字会糊；所以卡片里的小块一律用"更暗的凹陷材质"，形成真实的凹凸关系。

## 二、色板

| 用途 | 色值 |
| --- | --- |
| 页面底色 | `#05070c`（近黑带蓝调） |
| 玻璃卡片 | `rgba(255,255,255,.055)` |
| 侧边栏材质 | `rgba(16,20,28,.72)` |
| 凹陷区域 | `rgba(8,11,17,.42)` |
| 细线边框 | `rgba(255,255,255,.10)`，柔和版 `.06` |
| 顶边高光 | `rgba(255,255,255,.18)` |
| 主文字 / 次要 / 三级 | `#f4f6fa` / `rgba(236,240,248,.76)` / `rgba(236,240,248,.52)` |
| 强调蓝 | `#0a84ff`（悬停 `#3a9bff`） |
| 成功 / 提醒 / 危险 | `#30d158` / `#ffd60a` / `#ff453a` |

玻璃上的文字不用中性灰，而是用对比度更高的近白色，并给次要文字加 500 字重——这是 Apple 讲的"vibrancy"，保证在移动的背景上依然清晰。

## 三、圆角与间距

圆角按元素大小分级，整体偏大：小标签 10px，按钮与输入框 14px，卡片 18px，大面板 22px，顶部工具条 28px，状态胶囊用全圆角。间距仍按 4px 基数（4 / 8 / 12 / 16 / 24 / 32 / 48）。

## 四、字体与排印

- 字体优先用系统字体（`-apple-system` / `Segoe UI Variable` / `PingFang SC`），中文自动回退到微软雅黑与苹方。
- 字距随字号变化：主标题 `-0.022em`（收紧），卡片标题 `-0.012em`，正文接近 0，小字和标签略微放开（`+0.01em` 到 `+0.06em`）。
- 行高与字号反向：大标题 1.1，正文 1.55 至 1.65。
- 层级靠"字重 + 字号 + 行高"一起建立，不是只靠放大字号。

## 五、交互反馈

- **按下即反馈**：按钮、导航、分段控件在 `:active` 立即缩到 0.97，不等松开。反馈必须发生在按下的瞬间。
- **材质出现用"实体化"而不是淡入**：切换模块时同时做透明度 + 缩放 + 轻微位移，读起来像一块玻璃就位。
- **交互元素用一体的缓动曲线** `cubic-bezier(.32,.72,0,1)`，避免不同元素各用一套时长。
- 输入框聚焦时展开 4px 的蓝色光环，并且底色轻微染上强调色，让"当前在哪个输入框"一眼可见。

## 六、可访问性

规范里内建了三组媒体查询，不依赖用户手动设置：

| 用户偏好 | 界面的响应 |
| --- | --- |
| `prefers-reduced-motion: reduce` | 去掉位移与缩放，只保留极短的透明度变化 |
| `prefers-reduced-transparency: reduce` | 玻璃换成实色，关掉模糊，保证可读性 |
| `prefers-contrast: more` | 换成近实底 + 更明显的边框与更高的文字对比度 |

另外 `color-scheme: dark` 会让系统下拉框、滚动条也跟随暗色，避免出现刺眼的白色原生控件。

## 七、答辩时可以这样表述

界面不是套模板，而是按 Apple 的材质层级方法自己搭的一套暗色玻璃系统：结构区域用更重的材质、交互区域用更轻的材质，同一处不叠加两层浅色玻璃；底层铺环境光斑，让玻璃有真实折射；字距随字号调整，小字不挤、大标题不散；并按系统偏好自动降级动态、透明度与对比度。这些细节共同支撑"作品完成度"这一评分项。
