# 把网站放到公网

比赛要求作品必须能在公网访问，只能在校园网或本机访问的作品会被判无效。下面按推荐顺序给出三种做法。

## 一、云服务器（推荐）

1. 买一台轻量应用服务器，配置 2 核 2 吉以上，系统选 Ubuntu 或 Windows Server 都可以。学生机通常十几元一个月。
2. 把整个 `健身智能体` 文件夹上传到服务器（Windows 用远程桌面复制，Ubuntu 用宝塔面板或 scp）。
3. 在服务器上安装 Python 3.11 或 3.12，然后运行 `一键安装.ps1`（Windows）或手动执行 `pip install -r requirements.txt`（Ubuntu）。
4. 启动服务：Windows 运行 `一键启动网站.ps1`；Ubuntu 执行

```bash
cd 网页端
python -m uvicorn app:app --host 0.0.0.0 --port 8000
```

5. 在云服务商的控制台里，把安全组（防火墙）的 8000 端口放开，然后就能用 `http://服务器公网IP:8000` 访问。

## 二、加一个域名与 Nginx（想让网址更好看时）

用 Nginx 反向代理到 8000 端口，把 80 端口对外。注意必须调大上传体积限制，否则手机拍的长视频会返回 413 错误：

```nginx
server {
    listen 80;
    server_name 你的域名或IP;

    client_max_body_size 200m;

    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_read_timeout 300s;
        proxy_send_timeout 300s;
    }
}
```

## 三、内网穿透（临时演示用）

如果暂时没有服务器，可以用 cpolar、花生壳这类隧道工具，把本机的 8000 端口映射到公网地址。适合答辩前一天做演示，但要求电脑一直开着、网络一直在线，风险比云服务器高，建议只作为备用方案。

## 四、必须提前确认的三件事

1. **评审期间保持在线**：提交作品后到评审结束前，服务不能关，电脑不能睡眠。
2. **手机能打开**：用手机流量（不要用校园 WiFi）打开公网地址测试一遍，确认在外部网络下也能访问。
3. **上传大视频不报错**：用一段 20 秒左右的手机视频走一遍完整流程，确认上传、分析、播放都正常。

## 五、如果服务器性能紧张

姿态分析是 CPU 计算，单次分析大约占用 1 到 3 秒的 CPU 时间。演示与试用阶段并发很低，2 核足够。如果同时有多人上传，会在后台排队，不会崩溃，只是等待时间变长。
